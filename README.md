### Wine quality Data Analysis
**Code:** [`Wine Quality Data Analysis.ipynb`](https://github.com/prmjtsingh/my-projects/blob/main/Projects/Wine%20Quality%20Data%20Analysis.ipynb)

**Goal:** To determine the quality of wine.

**Description:** The dataset is related to red and white variants of the Portuguese "Vinho Verde" wine.  Due to privacy and logistic issues, only physicochemical (inputs) and sensory (the output) variables are available (e.g. there is no data about grape types, wine brand, wine selling price, etc.).

These datasets can be viewed as classification or regression tasks. The classes are ordered and not balanced (e.g. there are many more normal wines than excellent or poor ones). Outlier detection algorithms are used to detect the few excellent or poor wines. Also, we are not sure if all input variables are relevant. So, feature selection methods are used to test input variables.
The output is the quality of wine (score between 0 and 10).

**Skills:** Data cleaning, Data analysis, Correlation matrices, Data visualization.

**Technology:** Python, Pandas, Numpy, Seaborn, Matplotlib.

**Results:** Using Python functions, the analysis revealed the scoring of different types of wine.

### Loan Default Study
[Power BI file](https://github.com/prmjtsingh/my-projects/blob/main/Projects/Loan%20Study.pbix)

**Description:** The loan default dataset contains information about borrowers who have applied for a loan. Each record represents a borrower's information at the time of loan application. Assuming that the loans were disbursed to all borrowers, analysis is performed and a Power BI report is created to assist bank officials in making better decisions about who should be granted loans and who should not, considering the large number of cases where people defaulted.
